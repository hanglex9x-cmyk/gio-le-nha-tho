# Giờ Lễ Nhà Thờ Toàn Quốc

Web app mobile xem giờ lễ các nhà thờ Công giáo Việt Nam.

- Tìm giờ lễ theo tên nhà thờ, tỉnh/thành, giáo phận
- Lọc Hôm nay / Chúa Nhật / Thứ Bảy lễ vọng / Ngày thường, đếm ngược lễ tiếp theo
- Bản đồ Leaflet/OpenStreetMap, GPS tìm nhà thờ gần nhất, chỉ đường Google Maps
- Tra thêm nhà thờ quanh vị trí (bán kính 7km) qua Overpass/OpenStreetMap
- Form đóng góp / báo giờ lễ sai

V1: dữ liệu mẫu 24 nhà thờ chính tòa / nổi tiếng 3 miền, giờ lễ ghi rõ "cần xác nhận".
Bản chính thức sẽ nạp cơ sở dữ liệu Google Sheet toàn quốc vào app này.

Live: https://hanglex9x-cmyk.github.io/gio-le-nha-tho/
